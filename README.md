# FFH v1.177 → Android APK

Рабочий репозиторий для восстановления Unity-проекта из Windows-сборки **Femboy Futa House v1.177** и дальнейшей сборки Android ARM64 APK.

Первый workflow делает этап, который не требует Unity-лицензии:

1. скачивает исходный ZIP с Google Drive;
2. извлекает вложенную v1.177;
3. восстанавливает Unity-проект через AssetRipper;
4. добавляет mobile/touch код;
5. сохраняет компактный диагностический артефакт для автоматического анализа следующего шага.

После успешной реконструкции будет добавлена финальная APK-сборка.
